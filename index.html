맡길 일 vs 내가 할 일

    

      
Aside에 맡길 일
  • 공개 사이트 검색·비교 (S2B·연수·대회)
  • 여러 페이지 내용을 표로 정리
  • 입력 직전까지의 반복 작업
  • 정해진 시간의 정보 수집(루틴)

      
내가 직접 할 일
  • 인증서(EPKI·GPKI) 로그인
  • 견적 요청·결제·계약
  • 게시·제출·전송 버튼 누르기
  • 비공개 공문·나이스·학생 개인정보 다루기

    

    
업무포털 공문 정리는 Aside에 맡기지 않고, 교육청 누리집·정보공개포털(open.go.kr)의 공개 문서로 대신합니다. 원문은 직접 확인하세요.

    3. 
      
  3. 나이스·업무포털, 학생 성명·연락처 같은 개인정보는 맡기지 않습니다. 화면과 내용이 외부 AI 모델로 전송될 수 있습니다.
    4. 
      
  4. 결과는 반드시 원문 링크로 확인합니다. 학교 PC 설치는 학교 보안 정책을 먼저 확인합니다.
